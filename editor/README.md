# Editor & Authoring

The editor is modular and feature-oriented:
- `scene/` hierarchy, gizmo, inspector
- `asset/` import settings and reimport flow
- `material/` material and shader graph contracts
- `animation/` state machine and timeline contracts
- `ui/` visual layout authoring
- `vfx/` particle graph authoring
- `world/` terrain/streaming tooling
- `debug/` visualization overlays
