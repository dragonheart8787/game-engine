# 雙線共用遊玩錨點（WeaveBound + Eidrix）

本檔為 [GDD.md](./GDD.md) 的**可驗證玩法契約**：兩個專案應對齊下列答案，避免「文件與實際遊玩脫鉤」。

## 核心問題（必須能回答）

| 問題 | 共用答案（v0 / Playable-A） |
|------|-----------------------------|
| 玩家每 10 秒在做什麼？ | **移動或走位**、**理解當前目標**、**對敵人施壓或閃避**、**推進至勝利條件**（到達目標區／擊敗威脅／完成當前任務步驟）。 |
| 為什麼要繼續玩？ | **下一個挑戰節點**（下一波敵人、下一關卡段落、下一任務步驟）帶來可預期的難度與回饋。 |
| 贏了什麼？輸了什麼？ | **贏**：達成關卡／任務勝利條件，進入結算或下一階段。**輸**：穩定度／血量歸零或時限失敗，可重開或回選單。 |
| 主樂趣軸 | **戰鬥遭遇為 spine**：WeaveBound 原型為 3D／2D 模擬下的走位、能力與資源迴圈；Eidrix MVP 以**邏輯鏈戰鬥**為同一 spine 的呈現；探索／解謎為衛星加料（與 [GDD.md](./GDD.md) §1 一致）。 |

## 可重複玩的最小循環

1. 進場 → 理解當前目標（HUD／教學一行字）。
2. 遭遇挑戰（敵人、地形、時間壓力或任務條件）。
3. 操作與決策 → 回饋（受擊、得分、提示）。
4. 勝利或失敗 → 結算或重開 → 可再次從選單進入。

## 維護

變更玩法主軸時，同步更新 **GDD**、**TDD 存檔欄位**（WeaveBound）與 **Eidrix 任務／關卡 YAML**。

存檔與設定的跨線語意見 [SAVE_CONTRACT_V1.md](./SAVE_CONTRACT_V1.md)；上架向支柱核取見 [COMMERCIAL_PILLARS.md](../COMMERCIAL_PILLARS.md)。
