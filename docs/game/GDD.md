# 遊戲設計文件（GDD）— 初稿（WeaveBound 可玩原型對齊）

> 本檔為 **第一階 Playable Prototype** 用的極小範圍；細節與技術邊界見 [TDD.md](./TDD.md)。  
> **與 Eidrix MVP 共用的玩法契約**（每 10 秒在做什麼、勝負意義、主樂趣軸）見 [PLAY_LOOP.md](./PLAY_LOOP.md)。

## 1. 遊戲類型與目標

- **類型**：單機、第三人稱或第一人稱 3D 動作／探索（引擎能力允許下再定稿）。
- **主 spine（Phase A 原型）**：**戰鬥與遭遇**為主——移動走位、能力（Dash／扇形技等）、資源（Focus／原型碎片）、到達目標或擊敗威脅；探索與解謎為衛星，不與本 spine 搶主敘事。細部循環與雙線對齊見 [PLAY_LOOP.md](./PLAY_LOOP.md)。
- **原型目標**：玩家能在**一個占位場景**中移動、暫停、返回主選單、**一個存檔槽**讀寫成功。
- **勝利／失敗（v0）**：可選「到達觸發器即 Victory」／「血量歸零即 GameOver」；數值占位。

## 2. 核心玩法循環（v0）

1. 啟動 → 主選單。
2. 新遊戲 → 載入占位關卡 → 自由移動與鏡頭（依引擎 demo 能力）。
3. 暫停 → 繼續或回主選單。
4. 主選單 → 讀檔（若存在）或設定（占位）或離開。

## 3. 主選單流程

| 選項 | 行為 |
|------|------|
| 新遊戲 | 清除執行關卡狀態，進 Loading → InGame |
| 讀檔 | 讀 slot0，成功則 Loading → InGame，失敗則提示 |
| 設定 | 開占位面板（解析度、音量日後接 TDD） |
| 離開 | 關閉應用 |

## 4. UI 流程（v0）

- **主選單**：四個選項 + 版本號小字。
- **HUD**：血量條（占位數字）、暫停提示鍵位。
- **暫停選單**：繼續、回主選單、存檔（寫 slot0）。

## 5. 關卡與內容（v0）

- **單一占位場景**：無劇情要求；地面 + 玩家出生點即可。
- **敵人（可選）**：單一巡邏或站立 AI 占位，行為表後續擴充。

## 6. 經濟／任務（v0）

- **原型（M1.5）**：WeaveBound 使用 **碎片（scrap）**＋**Focus** 的最小閉環（擊殺取得、按鍵兌換 Focus）；經 **WORL** 鍵 `kWorldKeyPrototypeScrap` 與 slot0 一併持久化，見 [SAVE_CONTRACT_V1.md](./SAVE_CONTRACT_V1.md)。
- 完整背包與任務線在 **Vertical Slice** 擴充 TDD 欄位與 chunk；Eidrix 進度仍以任務 JSON 為權威。

## 7. 與引擎里程碑的關係

- **Prototype**：本 GDD §2–§5 可驗證即達標。
- **Vertical Slice**：補一條任務線、簡戰鬥、商店占位、對話框。
- **Production**：多關卡、完整存檔遷移、教學與平衡表。
