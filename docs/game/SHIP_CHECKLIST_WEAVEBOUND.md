# WeaveBound 原型「接近發行」驗收清單（對齊 PLAY_LOOP）

參考：[PLAY_LOOP.md](./PLAY_LOOP.md)

## 發行主模式

- **主程式**：`weavebound_game_prototype`（`--play` 互動模式）。
- **驗證**：CI 模式（無旗標／`--ci-gameover` 等）維持通過。

## 可勾選項目

### 進場

- [ ] 主選單可開新局、讀槽（與現有 L 鍵／流程一致）。
- [ ] 進入遊戲後有單行 HUD（標題列或日後 ImGui）。

### 目標可讀

- [ ] 多段落戰役下，玩家能辨識目前段落目標（終點座標／清敵提示）。

### 挑戰循環

- [ ] 近戰／遠程威脅與走位有意義。
- [ ] 段落之間難度或目標有變化。

### 回饋

- [ ] 受擊、勝利、失敗有最小音效或可關閉提示音（Windows 下）。
- [ ] 段落完成與最終勝利有可區分回饋（標題列或日後 UI）。

### 勝敗與重玩

- [ ] 血量歸零 → GameOver → 確認回選單。
- [ ] 最終目標達成 → Victory → 確認回選單；中間段落完成不結束整局。

### 發布物

- [ ] `game-engine/README.md` 含 Release 建置與執行檔位置說明。
