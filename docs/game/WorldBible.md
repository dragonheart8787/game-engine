# World Bible — 初稿占位

本文件為**世界觀、地理、派系與時間線的單一真實來源**（支援任務／對話／關卡文案）。

## 1. 高概念（待填）

- 一句話故事
- 玩家扮演的角色與動機

## 2. 地理與關卡

- 世界地圖區劃（區域名、氣候、可玩關卡對應）
- 關卡順序與解鎖條件（與 GDD 任務階段對齊）

## 3. 派系與角色

- 派系表：名稱、目標、與玩家預設關係
- 主要 NPC：一句話定位、可選任務線 ID

## 4. 規則與科技／魔法

- 世界內允許的科技或魔法邊界（影響戰鬥與關卡機關設計）

## 5. 時間線

- 故事前史要點（條列）
- 遊戲內時間跨度（日／週／年）

## 6. 與任務資料的連結

- 任務 ID 命名規則（例：`main_01`、`side_forest_02`）
- 劇情變數命名空間（與 TDD 存檔／Quest chunk 對齊）
