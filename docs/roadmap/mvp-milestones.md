# MVP Milestones

## M1: Runnable Core
- Engine loop lifecycle (init/update/render/shutdown)
- Scene/component model contract
- Asset GUID + dependency metadata schema
- Minimal input and logging

## M2: Authoring & Pipeline
- Scene/prefab/material format definitions
- Import/reimport protocol for GLTF/texture/audio
- Incremental build manifest model

## M3: Release & Services Foundation
- Package manifest + patch metadata schema
- Crash report envelope format
- Auth and matchmaking API contracts

## M4: Ecosystem Bootstrap
- Plugin manifest and lifecycle contracts
- Package registry metadata schema
- Sample plugin and minimal sample game
